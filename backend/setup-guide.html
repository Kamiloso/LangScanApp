Environment Setup & Deployment

Configuration and execution steps for the local Windows development environment.

Development Mode

Local / Windows
Prerequisites
  • Windows machine
  • Docker
  • .NET environment
1

Run the database

  • Run the ./PostgreSQL/database.bat script.
  • Start the database with the script and wait for it to fully start.
    Note: Don't forget to stop the database instance once you finish working.
  • You can detach from the process and perform additional actions (e.g., open pgconsole).
2

Run the backend

  • Run the ./WebAPI/run.bat script.
  • Create the secrets template using the script.
  • Obtain your API keys from any of the supported providers (Gemini, OpenAI, or Grok) to generate learning material on demand.
  • Fill the secrets template with your API keys (ensure this file remains listed in .gitignore).
    Info: Adding API keys is optional in development, though sending AI requests without them will result in internal server errors.
  • Start the backend using the script.
  • When updating backend code, manage EF Core migrations using the ./PostgreSQL/migrator.bat script.

Production Mode

Server / Linux
Prerequisites
  • Linux machine
  • Docker
1

Installation & Lifecycle

  • Traverse to an empty target directory.
  • Download the update script and grant execution permissions: 
    curl -fsSL "https://raw.githubusercontent.com/Kamiloso/LangScanApp/production/backend/Build/update.sh" -o "update.sh"
chmod +x update.sh
  • Download or update the environment (an existing .env file will not be overwritten): 
    ./update.sh
  • Fill the .env template with the required environment variables.
    Note: At least one AI provider key (Gemini, OpenAI, or Grok) is required in production.
Start environment
docker compose up
Stop environment
docker compose down
Full reset (nuke volumes)
docker compose down -v
Caution: Running docker compose down -v removes all associated volumes and permanently resets persisted data.
